Behavior — What should happen?

Beyond the UI, how should the consent banner actually function?

1. Block Google tracking until consent?

Currently gtag.js loads on every page visit. Under GDPR, tracking scripts must not fire before consent.

A

Yes — Gate tracking behind consent

Google Analytics/Ads only loads after user clicks "Accept". On "Refuz", it never loads. This is the GDPR-compliant approach.

B

No — Just show the banner

Banner is purely cosmetic — tracking loads regardless. Not GDPR-compliant but simpler. The banner just informs.

2. Remember the user's choice?

Without persistence, the banner shows on every page visit. With localStorage, it only shows once.

A

Yes — Remember with localStorage

Saves choice to localStorage. Banner hides permanently after first interaction. User can still change preference via a "cookie settings" link in footer.

B

No — Show on every visit

Banner appears every time the page loads. More annoying but ensures fresh consent each visit.

3. Re-open settings link?

Once accepted/refused, should there be a way to change the preference?

A

Footer link — "Setări cookie-uri"

Add a small link in the footer to reopen the banner. Standard practice, users can withdraw consent anytime.

B

None — One-time choice only

Simpler. User clears browser data to reset. Less ideal for GDPR but acceptable for a small business site.
